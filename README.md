# Rust Level Editor

This project is a 2D level editor built in Rust using egui/eframe. It features:
- A floating toolbox with select, erase, and creation tools (Coin, Ork, Danger pit)
- Polygon drawing and editing (point-by-point creation, move polygons/points)
- Entity placement (Coin, Ork, Danger pit)

## How to Run

1. Install Rust: https://rustup.rs/
2. Run: `cargo run`

## Notes
- Toolbox and entity icons are placeholders. Replace with your own assets as needed.
- All code is in the root directory.
