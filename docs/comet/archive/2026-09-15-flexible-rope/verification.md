## Risks and skipped work

- While held, the raw links array has one link-to-link pair straddling the hand whose endpoint distance is not seg_len (up to ~36% short); it is exact once the hand node the spec calls for is inserted (the drawn polyline and the constraint solver both use it), so the invariant holds in the spec's terms but a reader of RopeChain::links alone could see it as a stretch.
- Two archived tests were adapted (chain stilled before the regrab, chain speed asserted instead of the now-unused free-pendulum ang_vel); I judged both legitimate, but A5's literal 'unchanged' wording is no longer true of the test text.
